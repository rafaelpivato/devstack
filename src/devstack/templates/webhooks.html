Only registered applications with a declared container port are selectable. The application must verify the provider's webhook signature or token. Routes are not authentication.

Public access is a separate decision

After installation, an administrator can explicitly enable a webhook-only Tailscale Funnel on HTTPS 8443. This is never enabled by saving a route. It does not expose the dashboard on 443 or ordinary development ports.

sudo python3 /usr/local/lib/devstack/webhook_funnel.py

To disable this public endpoint:

sudo python3 /usr/local/lib/devstack/webhook_funnel.py --disable
