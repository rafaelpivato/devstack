# v0.5.2 clean-break audit

v0.5.2 deliberately replaces v0.5.1's singleton state and runtime with
the accepted **multiple durable projects / one globally active runtime**
architecture described in ADR-0001.

Deleted the old `devstack.web` HTTP server, `devstack.runtime` daemon,
legacy Compose/task/project storage and import helpers, old dashboard state
and ports inventory, old webhook app, corresponding frontend assets,
obsolete service units and their v1-only test fixtures.

The **only** installed console entry points are now `devstack-control`
and `devstack-web-v2`. No `devstack` alias points to a removed web server;
a real SSH CLI is explicitly deferred beyond v0.5.2.

Preserved `devstack.github_ssh` because native v2 imports use its
secure GitHub key helpers, and `devstack.update_control` because v2 uses
its unprivileged stable-release update trigger. Preserved standalone scripts
for Tailscale private access/onboarding, webhook Funnel and safe updater.

The release remains clean-install only. There is no migration path from
legacy `projects.json`, `runtime.json` or singleton state. Tests
`test_v052_clean_break.py` protect that design against regressions.
