# v0.5.2 Stage 5M — direct private Compose ports over Tailscale

**Minimal, read-only networking**. No proxy, Tailscale Serve route, reverse
proxy, Docker port rewrite, extra process, external exposure, or auto-publish.

With one active project, query `tailscale ip -4` on the privileged controller.
Only a valid tailnet IPv4 from the Tailscale CLI is accepted. Inspect **running
Compose service containers** with their immutable project UUID + current
activation generation verified via Docker labels. Only exact TCP
`NetworkSettings.Ports` published mappings where `HostIp` is the server's
**current Tailscale IPv4** are advertised.

- Published on `100.x.y.z:18080` → direct `http://100.x.y.z:18080/` link.
- Published on `0.0.0.0`, `::`, `127.0.0.1`, or a non-Tailscale host
  address → **never** described as a private Tailscale endpoint.
- No published TCP ports or Tailscale unavailable → show a meaningful empty
  state; do not change Compose or bind ports automatically.
- `applications` are optional friendly labels and optional container-port
  filters. They are **not** required for displaying a Compose port and they
  cannot publish a new one.
- An inactive project, a stopped service, a stale generation, a detached
  one-off job, or a foreign-owned Docker container → no private URL.
- TCP endpoints without HTTP servers remain just network endpoints; the
  displayed `http://` shortcut assumes the application speaks HTTP.

Native read-only API:
`GET /api/v2/projects/<project-uuid>/private-ports`.

Mobile project page displays direct links with a refresh option. The user's
device must be logged into the same tailnet. The app must listen on the
appropriate container interface and Docker Compose must **explicitly**
publish the desired host-port mapping to the Tailscale IP; DevStack does not
secretly change a `127.0.0.1` or wildcard bind.

Regression suite: `test_v052_private_ports.py`, plus the real Docker
A → B → A smoke scenario asserting that loopback-only publish mappings never
become advertised as Tailscale-private.

Architecture: ADR INV-02/03/06/08, AC-03/10/13. Tailscale Serve for DevStack's
private management UI is unchanged. This is separate from opt-in Funnel for
webhooks.
