# v0.5.2 Stage 5F — project-scoped Git inspection and fast-forward

**Unreleased integration change.** Git operations are owned by the controller,
never by Flask. They take explicit immutable project and repository IDs and
resolve existing registered checkouts below the project's private workspace.

- Inspect branch, HEAD, dirty state, upstream and cached ahead/behind counts.
- Fetch `origin` then fast-forward only from a clean checked-out branch tracking
  `origin`, with an expected-HEAD precondition. Diverged repositories refuse
  automatic merges, and no checkout changes while any project is executing.
- Git operations cannot change managed Compose/apps/tasks, trigger source
  template synchronization or activate workloads.
- The v2 project dashboard links to a repository detail page; the same
  operations are available via explicit project-scoped JSON endpoints.

**Limits:** Git fetch is currently a bounded synchronous operation (15 seconds),
not a general Git job queue. New-repository cloning, SSH credential
provisioning and reviewed `.devstack/` configuration sync are separate Stage
5 follow-ups. Their missing functionality remains a v0.5.2 release gap.
