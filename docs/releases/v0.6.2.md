# DevStack v0.6.2 — stabilization, diagnostics and accessible appearance

**Candidate for owner review. Not merged into main, tagged, or published.** The most recent published stable release remains v0.6.1 until the owner completes the final squash-merge and the main-only release workflow publishes this version.

## Changes

- **#80 runtime/update clarity.** A saved browser runtime request is read-only reconciled against controller-owned receipts on return/reload. The screen explicitly distinguishes pending/unknown/queued/running/succeeded/failed/interrupted outcomes, exposes safe timestamps and controller error codes, offers a copyable summary **without raw idempotency keys**, and keeps same-key retries explicitly confirmed after an authoritative runtime read. Published release checks remain read-only with an active project; installation remains inactive-only. Show existing safe updater phase/result/exit metadata.
- **#81 private DevStack diagnostics.** Global Administration now exposes bounded 1-, 5-, 30-minute structured events for controller, web, runtime transitions and updater status/timestamps, including partial/unavailable-source and truncated states. A mobile-friendly button copies a safe snapshot on user action only. See [ADR-0005](../adr/0005-v062-safe-diagnostics.md) for least-privilege design and limitations. No privileged system logs, credentials, Docker socket or arbitrary shell.
- **#82 navigation.** An accessible 44px Administration cog remains visible in the shared shell, including at deeper project screens, with readable global context and no implicit activation.
- **#83 System/Light/Dark.** Device-local preference with pre-paint appearance and live System changes; higher-contrast semantic tokens for canvases, forms, code/logs, statuses and focus indicators. Critical states use words/icons/shapes rather than hue alone, with reproducible contrast and deuteranopia simulation regression tests.

## Operational and architectural guarantees

- Preserve multiple durable projects, no more than one active runtime, controller-owned Docker execution, guarded shared web/CLI IPC, private Tailscale dashboard and explicit runtime transitions only.
- Preserve the legacy dashboard at `/` and opt-in v0.6 React UI at `/__v06`. No default UI cutover in this patch.
- Build checked-in, deterministic frontend assets and ship them in a Python wheel; a deployed Ubuntu server needs no Node toolchain.
- Main-only release publisher remains unchanged. The assistant must **not** merge the integration PR, tag a version or publish this candidate.
