# DevStack v0.7.3 — Unified public ingress and automatic HTTPS cutover

This release consolidates DevStack's public integrations into one unprivileged
Python ASGI application `devstack-public` on loopback 8768, retaining the
private Gunicorn Web API on 8765 and the separate Docker-aware controller.

- Tailscale Serve private dashboard **HTTPS :8443** (tailnet only).
- Tailscale Funnel public **HTTPS :443** to `devstack-public`, supporting
  opt-in MCP at `/mcp` and registered project webhooks at `/hooks/*`.
- MCP preserves the bounded status/ping-only unauthenticated surface.
- Public webhook receiver forwards HTTP bodies directly to authorized Docker
  bridge destinations, using dedicated restricted controller IPC for
  admission leases and destination resolution only.
- Single release-owned, idempotent Tailscale network reconciler. No added
  general reverse proxy, container, network daemon or interactive migration.
- Compatible with older v0.7.2 independent updaters via a trusted
  release-owned installation hook; refreshes the standalone updater.
- On successful installation, **open the private dashboard on :8443**. The
  prior 443 tab may disconnect. Fresh cloud-init installs also use :8443.
- Existing external webhook callback URLs using :8443 must be updated
  with their providers to use public HTTPS 443.
- Public integration routes stay disabled until explicitly enabled, unless
  preserving a prior enabled legacy integration during automatic migration.
- Network cutover failures remain bounded and retryable, without
  overwriting unrecognized routes or exposing the private dashboard.

This is an unreleased candidate. GitHub CI and real-host public ingress tests
must pass before the owner squash-merges PR #103. Do not mistake CI/Tailscale
configuration alone for confirmed remote ChatGPT connectivity.
