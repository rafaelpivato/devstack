# DevStack v0.7.3 — Isolated Tailscale HTTPS listeners

This candidate release changes the managed Tailscale ingress topology to
private Serve HTTPS 8443 and path-scoped public Funnel HTTPS 443.

- No additional reverse proxy, container or daemon.
- Public MCP URL: `https://<node>.ts.net/mcp`.
- Public webhook URL: `https://<node>.ts.net/hooks/<name>`.
- Private dashboard URL: `https://<node>.ts.net:8443/`.
- Default-deny public 443 root; no public dashboard forwarding.
- Web-first guarded migration from v0.7.2: verifies private 8443 before
  removing the legacy private 443 handler and provisioning public 443.
- Explicit confirmation and Web/root-broker actions for legacy webhook
  disable and new public 443 webhook enable/disable; never silently break callbacks.
  This works from upgraded wheels without depending on a stale host helper script.
- Every route change checks exact pinned identity and existing allowlisted
  Tailscale state, refuses foreign routes, and provides bounded diagnostics.
- Original MCP capability remains status and ephemeral ping only. No
  additional unauthenticated host/project privileges.

**Upgrading existing installations:** Open private Web Administration →
ChatGPT / MCP after installing the release; follow the on-screen migration
and copy the future dashboard address before the old tab disconnects.
Existing external webhook URLs must be changed by the provider operator
after explicit migration. Do not use SSH or reset Serve/Funnel.

**Acceptance evidence:** CI (Python, frontend, Docker smoke, Ubuntu systemd)
plus real host and independent public TLS/MCP tests. Green CI alone does not
prove ChatGPT cloud connectivity, especially given issue #101. This file
describes the release candidate, not a published release.
