# DevStack v0.7.8 — MCP repository and workstation management

Two workstreams in one feature PR, built on v0.7.7's direct shared Unix IPC
and owner-approved all-or-nothing OAuth.

### Repository management
- Inspect/change manual/check/update synchronization policy.
- Inspect/edit restart/redeploy mappings and recent repository reactions.
- Durable async update-all and repository-add operations with status tools.
- Branch preview and revision-fenced branch apply, optional repository selector.
- Existing Git checkout, runtime ownership, dirty worktree and concurrency
  safeguards remain in the controller; no new Git execution path.

### Workstation management
- Create/import/rename projects with durable import status.
- Inspect/save managed Compose YAML (expected revision).
- Inspect/replace complete applications/tasks lists (expected revision).
- Review/apply source template changes (explicit selection and revision).
- List/upsert/remove project webhook routes.
- Compose build/restart job, controller-validated disposable container command,
  and read private application port status.

### Compatibility and validation
- Existing MCP OAuth connections and 19 v0.7.7 tools remain unchanged.
- Every new management operation uses exact existing controller IPC, independently
  of the private Web server. No new services, roles, grants, approval screens or
  direct Docker/host-shell access.
- 26 new MCP tools, with controller ownership and revision checks.
- Public request body cap 64 KiB, matching the IPC message bound.
- GitHub CI: Python unittest and MCP tool discovery, frontend integrity,
  Docker smoke and fresh Ubuntu systemd/Unix-socket permissions.

### Acceptance
Reconnect only if the ChatGPT tool inventory is stale. Ask MCP for project
details and sync policy; review configuration without saving; optionally
exercise a deliberately selected write and verify its operation receipt.
No automatic runtime or project changes happen on upgrade.
