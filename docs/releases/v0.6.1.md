# DevStack v0.6.1 — Mobile interaction polish

**Patch candidate for owner review.** This release is not published until this PR is reviewed, merged into `main` by the owner, and the main-only release workflow completes.

## Changes

- Separate the job-output **Copy output** and **Load new output** buttons into a wrapping, spaced control row with distinct touch targets on narrow iPhone Chrome/Safari layouts. The copy-result feedback also has its own spacing.
- Make the shared DevStack wordmark a semantic, keyboard-accessible link to the v0.6 entry/home (`/__v06`) through the existing client-side navigation path. Visiting home reads the authoritative controller state; it does **not** activate or switch projects.
- Introduce two muted icon-only accent tones (blue and amber) on selected workspace lanes, retaining the neutral dark base, teal accent and non-color status labels. Avoid additional decorative colors in data/log/administration screens.

## Release and safety

- Python and frontend package/lock versions are `0.6.1`; immutable compiled v0.6 assets are rebuilt and checked in, with no Node requirement on the Ubuntu server.
- Existing controller/IPC, one-active-runtime, private access, CLI and updater behavior are unchanged.
- The redesigned UI **remains** opt-in at `/__v06`, while the existing `/` dashboard remains the default. Root cutover and real host acceptance require separate approval.
- Required frontend typecheck, tests, full online security audit, reproducible tracked assets, Python tests and Docker/Ubuntu smoke gates must pass before release.

The owner alone reviews and merges the final PR to `main`; only the main-only release workflow may publish `v0.6.1`.
