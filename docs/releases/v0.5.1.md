# DevStack v0.5.1 — GitHub-based Smoke Test sample

- In **Add project from GitHub**, select **Use Smoke Test example** to prefill
  the DevStack sample's public GitHub URL and the name `smoke`. Review the
  values and choose **Add project** to import using the standard workflow.
- The sample imports its Compose definition, default Web application and
  saved tasks directly from GitHub and retains source-sync metadata. It does
  not activate the runtime or start containers automatically.
- GitHub project imports accept **public HTTPS repositories without requiring
  a GitHub SSH key**. Explicit SSH clone URLs still use the configured,
  dedicated DevStack GitHub identity.
- Removed the legacy bundled Smoke Test install and refresh buttons/routes
  that bypassed the normal GitHub import workflow.
- No workspace-format changes, data migration or manual server
  reinstallation. The usual update timer installs this patch automatically.

The verified release workflow runs Python unit tests and real Docker smoke
integration, including a public HTTPS GitHub import, before publication.
