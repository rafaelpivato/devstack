# DevStack v0.7.0 — MCP connectivity and real controller health

- Adds an **opt-in, unauthenticated MCP gateway** as the separate `devstack-mcp`
  executable. It is disabled by default.
- Exposes two future-proof tools: `devstack_status` (installed version, live
  controller health via the existing web `/healthz` -> Unix IPC pathway,
  last ping) and `devstack_ping` (bounded, in-memory write returning pong).
- The MCP process does **not** get the controller's privileged socket, Docker,
  Git, project information, logs, file writes, or configuration access.
- Supports Streamable HTTP on `127.0.0.1:8768/mcp` with a configurable
  public hostname allowlist. Documents an isolated manual Tailscale Funnel
  endpoint on port 10000, leaving existing private access unchanged.
- Automated tests exercise the actual MCP -> Web -> controller IPC chain and
  write/read roundtrip, including a disconnected controller.
- No new permissions or public listeners are enabled on a normal upgrade;
  existing Web UI, CLI, and updater behavior is unchanged.

Before installing a release, follow the existing update safety and rollback
procedures. Automated tests do not prove a cloud-hosted ChatGPT connection.
Follow `docs/mcp-connectivity.md` to run the live test and turn public Funnel
off afterward. Authentication is required before future MCP tools gain
actual DevStack administrative capabilities.

- Administration → ChatGPT / MCP adds a copyable remote MCP URL and a deliberate
  Enable/Disable control. The existing trusted root updater provisions the
  dormant gateway and fixed-purpose systemd broker at upgrade time. Tailscale
  Funnel 10000 is controlled via a private literal-action request, with pinned
  identity and strict checks that preserve private Serve 443/webhook 8443.

- MCP and Funnel lifecycle/error diagnostics now appear in the existing
  time-filtered (1/5/30-minute), copyable Administration snapshot. SSH is
  not needed for routine MCP troubleshooting; see the repository Web-first
  operations policy in README.md and AGENTS.md.
