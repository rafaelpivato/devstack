# DevStack v0.7.0 — MCP Hello World connection proof

- Adds an **opt-in, unauthenticated MCP hello server** as a separate
  `devstack-mcp` executable (not started by the normal services).
- Exposes exactly `hello_read` and `hello_write`; the latter changes a
  bounded, volatile test value in memory. No controller IPC, Docker, Git,
  project information, logs, file access, or secrets.
- Supports MCP Streamable HTTP on `127.0.0.1:8768/mcp` with an explicit
  public hostname allowlist. Tailscale Funnel on separate HTTPS 10000 is
  described as a manual test path.
- No new permissions or network listeners enabled during a normal upgrade.
  Web UI/CLI/updater behavior is unchanged.

Before installing a new release, follow existing inactive-project updater
preflight, backup and rollback procedures. Do not treat automated tests as
proof of a real cloud-hosted ChatGPT connection. Follow `docs/mcp-hello.md`
and disable the public Funnel after testing. Authentication is required
before any future MCP tool gains real DevStack administrative privileges.
