# v0.5.2 Stage 5G — review Git template changes (read-only foundation)

**Unreleased integration work.** This stage introduces a controller-owned
three-way review of a linked GitHub project's managed source template:
1. `.devstack/` files in its registered Git checkout (upstream).
2. Immutable project-ID-scoped source import baseline (last imported snapshot).
3. Current SQLite applications/tasks and managed Compose YAML.

The review generates independent application, task and Compose change
identifiers, including new entries, updates, upstream removals (informational
only) and local customization conflicts. It computes a revision fingerprint
over all source, baseline and managed inputs to support later checked applies.

Browsing an inactive project and reading the source review never activates
Docker, updates Git, modifies managed settings, or removes definitions. Neither
web nor API receives an arbitrary file path or command. Git and project
operations are UUID-bound and controller-owned.

**Explicit remaining scope:** selective apply with optimistic revision checks,
approved item-by-item baseline advancement and crash-safe publication is not
part of this PR. The old singleton `project_sync.py` is not imported or
reused. This work does not satisfy AC-16 by itself.
