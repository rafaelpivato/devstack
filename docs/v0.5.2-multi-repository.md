# v0.5.2 Stage 5I — multiple native repositories per project

**Unreleased integration work. No singleton routes or runtime state.**

The controller now accepts independent GitHub HTTPS/SSH repositories under
`/var/lib/devstack/projects/<uuid>/repos/<name>`, without requiring a
`.devstack/project.toml` manifest or changing the project's linked template.

- One project can register multiple checkouts; the same remote in another
  project gets an independent checkout and registry UUID.
- `repository_add_submit` takes an explicit project UUID, validated GitHub
  URL, repository name, optional branch, and idempotency token. Its background
  worker is durable across browser disconnects. Status never exposes private
  keys or shell output.
- Clone is staged in a project-owned UUID directory. The coordinator lock
  guards final publication, Docker-ownership verification, and registration.
  A crash between publishing and registration is inspected on restart rather
  than blindly retried, deleted or adopted without verifying the remote.
- A failed clone retains its staging directory for operator inspection;
  the controller does not automatically remove any checkout or volume.
- Git status and safe fast-forward remain the same UUID-scoped operations
  introduced in PR #34.
- A private GitHub SSH identity is maintained by the controller user, never
  Flask. The dashboard can generate and display its **public key** and test
  GitHub authentication, but cannot read or replace a private key. Host keys
  use GitHub's HTTPS metadata, not an unverified SSH key scan.

## API

- `POST /api/v2/projects/<uuid>/repositories`, requiring CSRF and a
  32-character hex `Idempotency-Key` header.
- `GET /api/v2/projects/<uuid>/repository-adds/<uuid>` for operation status.
- `GET /api/v2/projects/<uuid>` lists all registered repositories.
- `GET /api/v2/github/ssh`, `POST /api/v2/github/ssh/generate`,
  `POST /api/v2/github/ssh/test` (private owner management).
- Existing `GET/POST /api/v2/projects/<uuid>/repositories/<repo-uuid>`
  provides read status / guarded fast-forward.
